# Starboard Reviews updates

Public installable packages, release notes and WordPress update metadata. The development repository stays private.

[Download the current plugin ZIP](https://raw.githubusercontent.com/andr3ixx/starboard-reviews-updates/main/releases/2.10.1/starboard-reviews-2.10.1.zip) · [Release notes](releases/2.10.1/README.md)

Install version 2.9.0 or later once to receive future update notifications in WordPress. Check Plugins or Starboard Reviews → Settings for updates. Updates are offered only when the release version increases. WordPress controls installation and optional automatic updates.

Packages include the plugin PHP/CSS/JavaScript, brand assets and bundled icon/font license notices, under their respective licenses. No development history, credentials, tests or internal previews are published.
