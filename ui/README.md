# Starboard UI updates

Public installable packages, release notes and WordPress update metadata. The development repository stays private.

[Download the current plugin ZIP](https://raw.githubusercontent.com/andr3ixx/starboard-reviews-updates/main/ui/releases/3.0.2/starboard-ui-3.0.2.zip) · [Release notes](releases/3.0.2/README.md)

Install Starboard UI 3.0.2 or later once to receive future update notifications. Existing paired sites can receive this first UI update after updating Reviews. Check Plugins or Starboard → UI → Advanced for updates. Updates are offered only when the release version increases. WordPress controls installation and optional automatic updates.

Packages include the plugin PHP/CSS/JavaScript, brand assets and bundled icon/font license notices, under their respective licenses. No development history, credentials, tests or internal previews are published.
